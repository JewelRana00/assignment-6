# FitLog — Workout Library

FitLog is a modern, responsive workout library and daily workout planning application. Users can browse workouts, view detailed exercise information, add exercises to today's plan, save workouts for later, and track their completed exercises.

The application is designed as a dark, no-nonsense gym companion focused on helping users **train with intent and log every set**.

## ✨ Key Features

### 1. 🏋️ Workout Library

- Browse all available workouts from the FitLog API.
- Responsive workout card grid for mobile, tablet, and desktop.
- Each workout displays:
  - Workout image
  - Category
  - Workout name
  - Equipment
  - Duration
  - Calories
  - Rating

### 2. 📋 Today's Workout Plan

- Add workouts to **Today's Plan** from the workout details page.
- Plan counter updates automatically in the navbar.
- Maximum of five lifts can be added to today's plan.
- View details, mark workouts as done, or remove them from the plan.
- Plan metrics update dynamically based on selected workouts.

### 3. ❤️ Save Workouts for Later

- Save any workout for future use.
- Saved workout count is displayed in the navbar.
- Saved workouts can be viewed from the **My Plan** page.
- Toast notifications provide feedback when workouts are saved or removed.

### 4. 🔎 Workout Details & Sorting

- Dedicated detail page for every workout.
- Displays workout description, categories, equipment, difficulty, sets, reps, duration, calories, rating, and instructions.
- Users can sort workout lists by:
  - Duration
  - Calories
  - Rating
- Interactive action buttons make it easy to add or save workouts.

### 5. 📱 Responsive & User-Friendly Interface

- Fully responsive design for mobile, tablet, and desktop.
- Responsive navigation, hero section, workout grid, detail page, and My Plan page.
- Loading states are displayed while workout data is being fetched.
- Custom 404 page is included for invalid routes.
- Toast notifications provide clear feedback for user actions.

## 🛠️ Technologies Used

- **Next.js 16** — React framework and application routing
- **React 19** — Building interactive UI components
- **TypeScript** — Type safety and better developer experience
- **Tailwind CSS 4** — Styling and responsive design
- **DaisyUI** — UI components and utilities
- **React Toastify** — Toast notifications
- **Next.js App Router** — Page navigation and routing
- **REST API** — Fetching workout data
- **Context API** — Managing plan and saved workout state
- **Local Storage** — Persisting workout plan data across reloads
